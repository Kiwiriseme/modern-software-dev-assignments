Run formatting and linting checks (from week4/ directory).

## Steps
1. Run `make format` to auto-format code with black and ruff --fix.
2. Run `make lint` to check for remaining lint issues.
3. Report:
   - Files modified by black
   - Any remaining ruff violations that couldn't be auto-fixed
   - Files changed (list them)
