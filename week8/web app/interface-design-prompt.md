# 网页记事本 - 界面设计提示词

> 原始界面参考：登录页（左品牌区 + 右表单区）与主界面（左导航 + 中内容 + 右详情）。

---

## 生成的提示词（
```
# 任务：构建一个「网页记事本」全栈 Web 应用

## 一、应用概述

构建一个现代化的个人笔记/待办管理 Web 应用，名为「网页记事本」。核心功能是让用户能够创建、管理、分类和查看笔记与 TODO 任务。整体风格为简洁、清新的中文界面，类似 Notion/Flomo 的轻量级体验。

---

## 二、数据模型

### 核心实体：Note（笔记）
{
  id: string (UUID),
  title: string,           // 笔记标题，如 "产品需求文档"、"笔记"
  content: string,         // Markdown 格式的正文内容
  type: "todo" | "text",   // 类型：TODO 待办项 或 文本笔记
  category: string,        // 分类标签，如 "工作"、"学习"、"生活"、"想法"
  isCompleted: boolean,    // 仅 todo 类型使用，是否已完成
  createdAt: datetime,
  updatedAt: datetime
}

### 辅助实体：Category（分类）
预置分类：全部、工作、学习、生活、想法。支持用户自定义新增分类。

### User（用户）— 如果实现认证功能
{
  id: string,
  username: string,
  email: string,
  password: string (hashed)
}

## 三、界面设计与布局（关键！请严格参照以下描述）

### 页面 1：登录/注册页
- 左右分栏布局，居中显示的白色卡片容器，带圆角和柔和阴影
- 左侧区域（约占 45% 宽度）：
  - 浅蓝灰色渐变背景（#f0f4ff 到 #e8f0fe）
  - 顶部：品牌 Logo 图标（笔记本/文档图标）+ 品牌名「网页记事本」+ Slogan「记录想法，管理任务，高效生活」
  - 中下部：3D 风格的等距插图（isometric illustration），展示一个打开的笔记本、一支笔、一盆小绿植，整体呈淡蓝色调
- 右侧区域（约占 55% 宽度）：
  - 纯白背景
  - 顶部大标题：「欢迎回来」，副标题：「登录您的账号，继续记录和管理您的内容」
  - 表单字段：
    - 用户名输入框（带用户图标前缀）
    - 密码输入框（带锁图标前缀 + 显示/隐藏密码眼睛图标）
    - 「记住我」复选框 + 「忘记密码？」链接（右对齐）
    - 主按钮：「登录」（蓝色填充 #4f6ef7，圆角，全宽）
    - 分隔线 + 「或」文字
    - 次要按钮：「使用 Google 账号登录」（白色背景，Google 图标 + 文字，带边框）
    - 底部：「还没有账号？立即注册」链接

### 页面 2：主界面（登录后）
- 三栏布局：

#### 左侧导航栏（固定宽度约 200px）
- 顶部：用户头像圆形图标
- 导航菜单项（垂直排列，选中项高亮为浅蓝色背景 + 蓝色文字）：
  - 全部（默认选中）
  - 工作
  - 学习
  - 生活
  - 想法
  - ＋ 新建标签（可展开添加自定义分类）
- 底部：设置齿轮图标

#### 中间内容区（主区域）
- 顶部操作栏：
  - 左侧：搜索框（占位符 "搜索 TODO..." 或 "搜索文本..."，随视图模式变化）
  - 中间：视图切换按钮组 — 「TODO」和「文本」两个 tab 按钮（选中态蓝色边框 + 蓝色文字，未选中灰白底）
  - 右侧：蓝色圆形 ＋ 新建按钮
- TODO 列表视图（当选择 TODO tab 时）：
  - 每行一条待办项，包含：
    - 左侧：方形复选框（未完成状态）
    - 中间：标题文字 + 彩色分类标签（如"工作"=蓝色、"学习"=绿色、"生活"=紫色）
    - 右侧：日期（相对时间格式，如"今天"、"明天"、或 "2024-01-26"）
  - 行之间有浅色分割线或间距
  - 整体为简洁列表样式，无卡片包裹
- 文本卡片视图（当选择「文本」tab 时）：
  - 2 列网格布局（Grid），每个卡片包含：
    - 卡片标题（加粗）
    - 分类标签（彩色小标签）+ 来源标签（灰色小字）
    - 内容摘要（1-2 行截断，灰色小字）
    - 日期（右下角）
  - 卡片有浅色边框和圆角，hover 时微上浮阴影效果

#### 右侧详情面板（点击某条笔记后滑出，或作为第三栏常驻）
- 顶部：返回箭头 + 笔记标题 + 「保存」按钮 + 更多操作（⋮）
- 元信息行：分类标签（彩色）+ 来源标签 + 「添加标签」链接
- AI 总结区块（可选增强功能）：紫色 AI 图标 + 「AI 总结」标题 + AI 生成的摘要文字
- 正文区域：Markdown 渲染的内容（支持标题、列表、代码块等格式）

## 四、核心交互流程

1. 登录 → 主界面：登录成功后跳转到主界面，默认显示「全部」分类下的 TODO 列表
2. 新建笔记：点击右上角 ＋ 按钮，弹出模态框或在右侧面板中打开编辑器，填写标题、选择类型（TODO/文本）、选择分类、编写内容
3. 切换视图：点击顶部的「TODO」/「文本」按钮切换列表/卡片视图
4. 筛选分类：点击左侧导航的分类名称，中间区域过滤显示对应分类的内容
5. 查看详情：点击列表中的条目或卡片，在右侧面板展示完整内容
6. 完成待办：在 TODO 列表中勾选复选框，标记为完成（可划线删除样式）
7. 搜索：在搜索框输入关键词，实时过滤当前视图的内容

## 六、技术要求

- 前端：Vue3
- 后端：Django
- 数据库：SQLite
- 认证：JWT token 认证（含 Google OAuth 可选增强）
- 状态管理：React Context
- Markdown 渲染：react-markdown + remark-gfm
```
