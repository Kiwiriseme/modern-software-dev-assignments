Current App Architecture — 便签管理应用

Django (DRF) + Vue.js (Vite) — 当前无登录/认证功能

Backend (Django + DRF)

Models:

  • 📝 Note — title, content, category, timestamps
  • ✅ Todo — title, content, category, due_date, is_completed, timestamps
  • 🤖 AISettings — API key, base_url, model (singleton)

API Endpoints:

  • GET/POST /api/v1/notes
  • GET/PUT/DELETE /api/v1/notes/:id
  • POST /api/v1/notes/:id/summarize-todos
  • GET/POST/PUT/PATCH/DELETE /api/v1/todos
  • GET/PUT /api/v1/ai-settings/1
  • GET /api/v1/categories

🔑 Authentication: NONE (open access)

Frontend (Vue 3 + Pinia + Vite)

Structure:

  • MainLayout.vue — single route
  • Sidebar.vue — category navigation
  • ContentArea.vue — card/list views
  • DetailPanel.vue — edit item
  • SettingsDialog.vue — AI config

🔑 Login page: NONE

Data Flow

Browser → Axios (/api/v1/*) → Django DRF ViewSet → SQLite
⚠ No auth middleware, no user isolation — all data is shared
