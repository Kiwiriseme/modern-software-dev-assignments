交互细节

🔴 未配置 API 时

点击 "AI 总结待办" → 弹出确认框：
"请先配置 AI API 设置"
两个按钮："去设置"（打开设置弹窗）、"取消"

🔄 Loading 状态

点击按钮后 → 按钮文字变为 "总结中..." + spinner 动画，按钮禁用防重复点击。
后端处理（调用AI API + 创建Todo）→ 响应返回

✅ 完成状态

按钮恢复正常 → Toast 通知：
"已添加 3 个待办事项" 或 "未发现待办事项"
Todo 列表自动刷新，Sidebar 计数更新
